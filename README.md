## Development

### Prerequisites

- Flutter SDK
- Dart SDK

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/Rystal-Team/zenstream.git
   ```

2. Install dependencies
   ```sh
   flutter pub get
   ```

### Running the App

```sh
flutter run
```

### Building the App

```sh
flutter build <platform>
```

Replace `<platform>` with `apk`, `ios`, `web`, `windows`, `macos`, or `linux`.
